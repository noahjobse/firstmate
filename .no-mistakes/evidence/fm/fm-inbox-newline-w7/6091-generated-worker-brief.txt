# Firstmate instruction inbox
Firstmate steers you through durable message files in '<FM_HOME>/state/demo-task.inbox'.
When a terminal message says an instruction is waiting there - and at any natural checkpoint when you are unsure - list '<FM_HOME>/state/demo-task.inbox'/*.msg, read and act on each message in numeric order, then acknowledge each handled message by moving it: `mv '<FM_HOME>/state/demo-task.inbox'/NNN.msg '<FM_HOME>/state/demo-task.inbox'/handled/`.
Read each record's entire body, including a final line that may not end in a newline; a line-reading loop that treats end-of-file-before-newline as failure will silently drop that content.
The move IS the acknowledgement: without it firstmate rings again and eventually treats you as stuck. An empty or absent inbox needs no action.
